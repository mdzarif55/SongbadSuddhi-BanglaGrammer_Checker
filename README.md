# সংবাদ শুদ্ধি — SongbadSudhhi (Bangla Grammar Checker)
### Professional Bengali Grammar & Proofreading System

**“সংবাদ শুদ্ধি”** বাংলাদেশের মূলধারার সংবাদপত্র, বার্তা সংস্থা ও ডিজিটাল নিউজরুমের সাংবাদিক, সহ-সম্পাদক (sub-editors) এবং কপি এডিটরদের জন্য তৈরি একটি পেশাদার প্রমিত বাংলা বানান, ব্যাকরণ ও সম্পাদকীয় নিরীক্ষা প্ল্যাটফর্ম।

---

## ১. প্রধান বৈশিষ্ট্যাবলী (Key Features)

1. **রক্ষণশীল ও বিশ্বাসযোগ্য সম্পাদকীয় নীতি (Conservative Newsroom Editing)**:
   - কোনো ব্যক্তির নাম, সাংবিধানিক বা প্রাতিষ্ঠানিক পদবি, রাজনৈতিক দলের নাম ও ভৌগোলিক স্থানের নাম কখনো নিঃশব্দে মুছে বা পরিবর্তন করা হয় না।
   - সকল তারিখ, সময়, পরিসংখ্যান, অর্থ ও পরিমাণের মান অপরিবর্তিত থাকে।
   - প্রত্যক্ষ উদ্ধৃতি (Direct Quotes) সুরক্ষিত রাখা হয়; উদ্ধৃতিতে কোনো ভুল থাকলে তা "সম্পাদকীয় যাচাই প্রয়োজন" ফ্ল্যাগ দিয়ে চিহ্নিত করা হয়।
   - ফৌজদারি বা আইনি সংবাদের ক্ষেত্রে আইনি সুরক্ষামূলক ভাব (যেমন: 'অভিযোগ উঠেছে', 'দাবি করা হয়েছে') অক্ষুণ্ণ রাখা হয়।

2. **বহুমাত্রিক বাংলা নিরীক্ষা ইঞ্জিন (Proofreading Categories)**:
   - **বানান (Spelling)**: বাংলা একাডেমি প্রমিত বানানরীতি (তৈরি, সরকারি, শ্রেণি, ইত্যাদি), অতৎসম শব্দে হ্রস্ব ই-কার, ণ-ত্ব ও ষ-ত্ব বিধান (পুরস্কার বনাম পুরষ্কার, আবিষ্কার বনাম আবিস্কার)।
   - **ব্যাকরণ (Grammar)**: সম্মানসূচক কর্তার সাথে ক্রিয়াপদের সংগতি (যেমন: 'তিনি বলেছেন' বনাম 'তিনি বলেছে'), দ্বৈত বহুবচন দোষ বর্জন ('সব সচিবরা' -> 'সব সচিব' বা 'সচিবরা')।
   - **বিরামচিহ্ন ও মুদ্রণশৈলী (Punctuation & Typography)**: বাংলা দাঁড়ি (।) ব্যবহারে দাঁড়ির আগের অবাঞ্ছিত স্পেস অপসারণ, দাঁড়ির পরে স্পেস সংযোজন, অপ্রয়োজনীয় ফুলস্টপ সংশোধন।
   - **সংবাদ সম্পাদনা (News Copy Editing)**: বাক্যের অযাচিত জটিলতা, আমলাতান্ত্রিক কাঠখোট্টা বুলি পরিহার ও প্রাঞ্জলতা বৃদ্ধি।
   - **সম্পাদকীয় যাচাই (Editorial Review)**: তথ্যের অমিল বা সূত্রের অস্পষ্টতা চিহ্নিতকরণ।

3. **নিরাপদ সংশোধন কর্মপ্রবাহ (Safe Correction Workflow)**:
   - একক সংশোধন গ্রহণ (Accept), বাতিল (Reject) বা পূর্বাবস্থায় ফেরা (Undo)।
   - ক্যারেক্টার অফসেটের ভিত্তিতে পেছনের দিক থেকে (descending order) নিরাপদে প্রতিস্থাপন, যাতে শব্দ পরিবর্তনের ফলে টেক্সট ক্ষতিগ্রস্ত বা ওভারল্যাপ না হয়।
   - মূল বনাম সংশোধিত লেখার তাৎক্ষণিক ভিজ্যুয়াল ডিআইএফএফ (Visual Diff) ও পাশাপাশি তুলনা (Side-by-Side View)।
   - এক ক্লিকে সংশোধিত সম্পূর্ণ লেখা কপি ও `.txt` ফাইল ডাউনলোড।

4. **প্রতিস্থাপনযোগ্য অভিধান ও ইউনিকোড নরমালাইজেশন (Replaceable Lexicon Engine)**:
   - ইউনিকোড এনএফসি (NFC) ক্যানোনিকাল কম্পোজিশন এবং যুক্তবর্ণের সামঞ্জস্য।
   - লেভেনস্টাইন ও ফোনেটিক ডিসট্যান্স ভিত্তিক প্রমিত বানানের বিকল্প প্রস্তাবনা।
   - ওপেন সোর্স বা নিউজরুমের নিজস্ব শব্দতালিকা আমদানির জন্য ডেডিকেটেড স্ক্রিপ্ট (`scripts/import-dictionary.mjs`)।

5. **গুগল জেমিনি (Google Gemini AI) ইন্টিগ্রেশন ও সুরক্ষিত অফলাইন ফলব্যাক**:
   - অফিসিয়াল `@google/genai` এসডিকে ব্যবহার।
   - এআই অফসেট যাচাইকরণ (Server-Side Offset Verification) যাতে কোনো বিভ্রান্তিকর অবস্থানে ভুল হাইলাইট না হয়।
   - এপিআই কি অনুপলব্ধ বা কোটা অতিক্রান্ত হলেও লোকাল ডিকশনারি ও রুল ইঞ্জিন দ্বারা নিরবচ্ছিন্ন কার্যক্ষমতা।

- **ফ্রেমওয়ার্ক**: [Next.js](https://nextjs.org/) (App Router)

## ৪. ইনস্টলেশন ও লোকাল সেটআপ (Local Setup)

### পূর্বশর্ত
- [Node.js](https://nodejs.org/) v18.0.0 বা তদূর্ধ্ব
- `npm` বা `pnpm` / `yarn`

### ধাপসমূহ

১. রিপোজিটরি ক্লোন করুন এবং প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
git clone <repository-url>
cd "Bangla Checker"
```

২. প্রয়োজনীয় প্যাকেজগুলো ইন্সটল করুন:
```bash
npm install
```

৩. পরিবেশ ভেরিয়েবল (Environment Variables) কনফিগার করুন:
```bash
cp .env.example .env.local
```
`.env.local` ফাইলটি খুলে আপনার Google Gemini API Key প্রবেশ করান:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash
MAX_ARTICLE_CHARS=25000
RATE_LIMIT_MAX_REQUESTS=40
RATE_LIMIT_WINDOW_MS=60000
```
> **টিপ**: API Key না থাকলেও অ্যাপটি লোকাল বাংলা একাডেমি অভিধান ও ব্যাকরণ রুলসের মাধ্যমে নিরবচ্ছিন্নভাবে কাজ করবে।

৪. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।

## ৬. নিজস্ব শব্দভাণ্ডার বা অভিধান আমদানি (Custom Dictionary Import)

আপনি যদি আপনার নিউজরুমের অভ্যন্তরীণ পরিভাষা বা উন্মুক্ত বাংলা শব্দকোষ সংযুক্ত করতে চান:

```bash
node scripts/import-dictionary.mjs --source path/to/wordlist.txt
```
ফাইলটিতে প্রতি লাইনে একটি করে শব্দ এবং অবশ্যই `UTF-8` ফরম্যাটে থাকতে হবে।

## ৭. ভার্সেল ডেপ্লয়মেন্ট গাইড (Vercel Deployment)

এই প্রজেক্টটি Vercel-এ শূন্য কনফিগারেশনে ডেপ্লয় করার জন্য সম্পূর্ণরূপে অপ্টিমাইজড:

১. প্রজেক্টটি আপনার GitHub / GitLab একাউন্টে পুশ করুন।
২. [Vercel Dashboard](https://vercel.com/)-এ গিয়ে "Add New Project" নির্বাচন করুন।
৩. ফ্রেমওয়ার্ক হিসেবে **Next.js** স্বয়ংক্রিয়ভাবে সনাক্ত হবে।
৪. Environment Variables সেকশনে নিচের ভেরিয়েবলগুলো যুক্ত করুন:
   - `GEMINI_API_KEY`: আপনার গুগল জেমিনি এপিআই কি
   - `GEMINI_MODEL`: `gemini-2.5-flash`
   - `MAX_ARTICLE_CHARS`: `25000`
৫. **Deploy** বাটনে ক্লিক করুন।

## ৮. নিরাপত্তা ও সম্পাদকীয় গোপনীয়তা (Security & Privacy)

- **ডেটা ধারণ নীতি**: ডিফল্টভাবে কোনো সাংবাদিক বা বার্তা সংস্থার প্রেরিত সংবাদের খসড়া ডেটাবেসে স্থায়ীভাবে সংরক্ষণ (persist) করা হয় না।
- **প্রম্পট ইনজেকশন প্রতিরোধ**: সংবাদের ভেতরের কোনো লেখাকে নির্দেশের অংশ হিসেবে গ্রহণ করা হয় না।
- **রেট লিমিটিং**: অস্বাভাবিক বা অপব্যবহার রোধে আইপি-ভিত্তিক স্লাইডিং উইন্ডো সুরক্ষা রয়েছে।
- **ক্লায়েন্ট সিকিউরিটি**: এপিআই কি শুধুমাত্র সার্ভার-সাইডে ব্যবহৃত হয়, ব্রাউজারের কোনো স্ক্রিপ্টে প্রকাশিত হয় না।
